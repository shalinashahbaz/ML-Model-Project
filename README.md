# Sales Prediction ML Model

This project is a Machine Learning based Sales Prediction System developed using Python.  
The model predicts sales based on input data and compares actual vs predicted sales using visualization.

## Project Overview

The main goal of this project is to analyze sales data and build a predictive model that can estimate future sales values accurately.

## Features

- Data preprocessing
- Machine Learning model training
- Sales prediction
- Data visualization
- Actual vs Predicted comparison graph
- Model performance evaluation

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-learn
- Jupyter Notebook

## Dataset

The project uses a sales dataset containing historical sales records for training and testing the model.

## Machine Learning Workflow

1. Load Dataset
2. Clean and preprocess data
3. Split data into training and testing sets
4. Train ML model
5. Predict sales
6. Visualize results

## Installation

Clone the repository:

```bash
git clone https://github.com/shalinashahbaz/ML-Model-Project.git
```

Move into the project directory:

```bash
cd ML-Model-Project
```

Install required libraries:

```bash
pip install -r requirements.txt
```

## Run the Project

```bash
python main.py
```

or open Jupyter Notebook:

```bash
jupyter notebook
```
